# LinKross

> Verify talent. Define the work. Prove it works.

개발 전문인력이 없는 초기 스타트업이 국내외 개발 프리랜서를 선정하고, 업무를 정의하며, 제출된 결과물의 실제 작동 여부를 검증할 수 있도록 지원하는 외주 개발 관리 플랫폼입니다.

## Background

초기 스타트업은 빠른 MVP 개발을 위해 외부 개발자를 활용하지만, CTO나 개발 리드가 없는 경우 다음과 같은 어려움을 겪습니다.

- 포트폴리오만으로 개발자의 실제 역량을 판단하기 어렵습니다.
- 사업 아이디어를 명확한 업무 범위와 완료 조건으로 작성하기 어렵습니다.
- GitHub에 코드가 제출되어도 기능이 실제로 작동하는지 확인하기 어렵습니다.
- 검수, 승인, 인보이스, 결제 및 증빙 기록이 여러 도구에 분산됩니다.

LinKross는 외주 개발의 `인재 선정 → 업무 정의 → 결과물 검수 → 승인 및 증빙` 과정을 하나의 흐름으로 연결합니다.

## Development

```bash
npm install
npm run dev
```

로컬 개발 서버는 기본적으로 [http://localhost:3000](http://localhost:3000)에서 실행됩니다.

페이지별 병렬 작업을 시작하기 전 [팀 라우트 가이드](./docs/TEAM_ROUTE_GUIDE.md)를 확인합니다. 공통 레이아웃과 라우트 계약, 페이지별 작업 경계를 정리해 두었습니다.

## Target Users

- CTO나 자체 개발팀이 없는 초기 스타트업 및 예비 창업팀
- 웹·앱 MVP 개발을 외부 개발자에게 맡기는 대표, PO, 운영 담당자
- 국내외 개발 프리랜서 및 소규모 개발사

## Core Features

### 1. Project Proposal & Freelancer Selection

발주자가 프로젝트 목표, 요구사항, 일정, 예산과 모집 기간을 등록하면 지원자는 프로젝트 수행 제안서를 자유 형식으로 제출합니다.

- 프로젝트에 대한 이해
- 구현 방식과 기술 스택 선정 이유
- 예상 작업 단계와 일정
- 결과물과 완료 계획
- 필요한 경우 예상 리스크와 대응 방안

발주자는 제안서 원문을 직접 확인하여 프로젝트 이해도, 기술적 판단과 실행 계획을 바탕으로 수행 적합성이 높은 프리랜서를 선정합니다. MVP에서는 제안서의 AI 요약·분류, 자동 점수와 지원자 추천을 제공하지 않습니다.

### 2. AI-powered 업무 명세서

원본 요구사항과 선정된 개발자의 질문 및 작업 계획을 바탕으로 다음 문서를 구조화합니다.

- 업무 범위 및 제외사항
- 주요 산출물
- 작업 일정 및 마일스톤
- 역할과 책임
- Acceptance Criteria
- Definition of Done

생성된 문서는 발주자와 개발자가 함께 수정하고 승인한 후 프로젝트의 공식 업무 및 검수 기준으로 사용합니다.

### 3. GitHub-based Executable Verification

개발자가 마일스톤에 GitHub PR과 커밋을 연결해 검수를 요청하면 제출된 코드를 안전한 별도 실행환경에서 검증합니다.

1. 제출된 Commit SHA 고정
2. 격리된 일회성 실행환경 생성
3. 소스코드 복제 및 의존성 설치
4. 빌드·실행 및 자동 테스트
5. 완료 조건별 결과와 실행 로그 제공
6. Preview를 통한 직접 기능 확인
7. 발주자의 최종 승인 또는 수정 요청

단순히 코드가 제출되었는지가 아니라, 사전에 합의한 기능이 실제로 작동하는지를 확인하는 것이 목표입니다.

### 4. Payment & Evidence

검수가 완료되면 인보이스 제출부터 지급 완료까지의 상태를 관리합니다.

- 인보이스 제출 및 승인
- 승인 금액과 지급 예정일 확인
- 지급 요청·처리 중·완료 상태 관리
- 검수 결과와 지급 기록 연결
- 통합 증빙 PDF 생성

통합 증빙에는 승인된 업무 명세서, Commit SHA, 테스트 결과, 최종 승인 내역, 인보이스와 지급 기록이 포함됩니다.

## User Flow

```text
요구사항 등록
    ↓
지원자의 자유 형식 수행 제안서 제출
    ↓
개발자 선정
    ↓
AI 업무 명세서 및 완료 조건 작성
    ↓
발주자·개발자 최종 승인
    ↓
GitHub PR 및 Commit 제출
    ↓
격리 환경에서 빌드·실행·테스트
    ↓
체크리스트 및 Preview 확인
    ↓
최종 승인 및 인보이스 제출
    ↓
결제 상태 관리 및 통합 증빙 생성
```
