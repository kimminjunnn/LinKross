## False FAIL 상세 (가장 중요)

정상 동작하는 앱을 실패로 판정한 항목입니다. 하네스가 남긴 관찰 결과를 그대로 옮깁니다.

- **login-fields**: 브라우저 시나리오 실행 중 오류가 발생했습니다.
- **login-bad-password-error**: 브라우저 시나리오 실행 중 오류가 발생했습니다.
- **todo-add**: 브라우저 시나리오 실행 중 오류가 발생했습니다.
- **todo-check**: 확인한 동작: /todos 경로 열기. 다음 단계에서 기대한 결과를 확인하지 못했습니다: checkbox 요소이 화면에 표시됨.
- **session-persist**: 확인한 동작: /todos 경로 열기 → button 요소이 화면에 표시됨. 다음 단계에서 기대한 결과를 확인하지 못했습니다: button 요소에 키보드 포커스가 있음.
