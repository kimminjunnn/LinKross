# LinKross 브랜드 에셋

LinKross의 공식 로고와 워드마크를 보관하는 디렉터리다.

## 공식 SVG

- `linkross-lockup-dark.svg`: 네이비 배경을 포함한 공식 락업
- `linkross-lockup-light.svg`: 흰색 배경을 포함한 공식 락업
- `linkross-lockup-orange.svg`: 브랜드 오렌지 배경을 포함한 공식 락업
- `linkross-lockup-on-*.svg`: 배경을 제거하고 여백을 줄인 UI용 락업
- `linkross-symbol-on-*.svg`: 원본에서 추출한 심벌 단독 에셋

파일명의 `on-light`, `on-dark`, `on-orange`는 에셋 자체의 배경색이 아니라 배치할 배경을 뜻한다.

## PNG 레퍼런스

- `linkross-lockup-dark.png`: 어두운 배경용 락업 레퍼런스
- `linkross-lockup-light.png`: 밝은 배경용 락업 레퍼런스
- `linkross-lockup-orange.png`: 브랜드 오렌지 배경용 락업 레퍼런스
- 화면에서는 가능한 한 SVG를 사용하고, PNG는 메타 이미지·문서·외부 서비스처럼 SVG를 지원하지 않는 경우에 사용한다.

## 사용 원칙

- 로고 비율, 색상, 글자 간격을 임의로 변경하지 않는다.
- 배경색에 맞는 변형을 선택해 충분한 대비를 확보한다.
- 앱 아이콘이나 favicon에는 워드마크를 제외한 `linkross-symbol-on-*.svg`를 사용한다.
- SVG 원본을 기준 자산으로 관리하고 PNG가 필요하면 용도와 크기에 맞춰 파생 생성한다.

브랜드 색상은 네이비 `#0F172A`, 오렌지 `#F97316`, 흰색 `#FFFFFF`다.
