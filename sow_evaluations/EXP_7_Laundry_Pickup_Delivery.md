# EXP 7: 세탁소 픽업/배송 관리 서비스 SOW 실험 결과

## 1. 생성된 마일스톤 및 DoD 목록

### M1: 회원가입 및 로그인 (23.11.01 - 23.11.15, 예산: $5,000)
- [ ] /signup에서 이메일과 비밀번호 입력 후 가입 완료 시 /login으로 이동됨
- [ ] /login에서 비밀번호를 틀리게 입력 시 '비밀번호가 일치하지 않습니다' 오류 메시지가 표시됨
- [ ] 로그인 상태에서 새로고침 시 세션이 유지되어 /orders 화면이 그대로 표시됨
- [ ] /login에서 존재하지 않는 계정으로 로그인 시도 시 '계정을 찾을 수 없습니다' 오류 메시지가 표시됨
- [ ] /logout 버튼 클릭 시 세션이 종료되고 /login 화면으로 이동됨
- [ ] 관리자가 /admin에서 기사 계정을 생성하고 발급할 수 있음

### M2: 픽업 주소 등록 및 기본 주소 지정 (23.11.16 - 23.11.30, 예산: $4,000)
- [ ] /addresses에서 새 주소 등록 시 별칭, 상세 주소, 요청사항 입력 후 저장됨
- [ ] /addresses에서 등록된 주소 중 하나를 기본 주소로 지정할 수 있음
- [ ] /addresses에서 동일한 주소를 중복 등록 시도 시 '이미 등록된 주소입니다' 오류 메시지가 표시됨

### M3: 픽업 주문 요청 및 중복 방지 (23.12.01 - 23.12.15, 예산: $6,000)
- [ ] /orders/new에서 등록된 주소 선택 후 세탁물 종류, 수량, 날짜, 시간대 입력 후 픽업 요청됨
- [ ] /orders/new에서 동일 주소, 날짜, 시간대에 중복 요청 시 '중복 요청일 수 있습니다' 안내 메시지가 표시됨
- [ ] 픽업 요청 버튼을 빠르게 여러 번 클릭해도 /orders 목록에 동일 주문이 1건만 생성됨 확인

### M4: 주문 상태 파이프라인 및 기사 배정 (23.12.16 - 23.12.31, 예산: $8,000)
- [ ] /admin에서 관리자가 픽업 대기 중인 주문을 특정 기사에게 배정할 수 있음
- [ ] /orders에서 기사가 자신에게 배정된 주문만 볼 수 있음
- [ ] /orders에서 기사가 배정된 주문의 상태를 '픽업 완료'로 변경할 수 있음
- [ ] /orders에서 '픽업 대기' 상태에서 '배송 완료'로 직접 변경 시도 시 변경이 거부되고 오류 메시지가 표시됨

### M5: 고객 주문 목록 및 상세 조회 (24.01.01 - 24.01.15, 예산: $5,000)
- [ ] /orders에서 고객이 자신의 전체 주문을 목록으로 확인할 수 있음
- [ ] /orders에서 진행 중인 주문과 완료된 주문을 구분해서 볼 수 있음
- [ ] /orders/:id에서 주문 상세 정보(현재 상태, 픽업 주소, 세탁물 종류, 담당 기사, 상태 변경 이력)를 확인할 수 있음
- [ ] /orders에서 주문이 하나도 없는 신규 고객이 접속 시 '아직 주문 내역이 없습니다' 빈 상태 화면이 표시됨

### M6: 주문 취소 및 재주문 (24.01.16 - 24.01.31, 예산: $4,000)
- [ ] /orders에서 '픽업 대기' 상태인 주문에 한해 고객이 직접 취소할 수 있음
- [ ] /orders에서 '픽업 완료' 이후 단계의 주문은 고객이 취소할 수 없고 관리자에게 문의 안내가 표시됨
- [ ] /orders에서 취소된 주문은 상태가 '취소됨'으로 바뀌고 목록에서 계속 조회됨
- [ ] /orders/:id에서 '다시 주문하기' 버튼 클릭 시 동일 주소와 세탁물 종류로 새 픽업 요청 화면으로 이동됨

### M7: 관리자 대시보드 및 주문 관리 (24.02.01 - 24.02.15, 예산: $8,000)
- [ ] /admin/dashboard에서 오늘 픽업 예정 건수, 오늘 배송 예정 건수, 현재 세탁 중인 건수, 기사별 담당 건수를 한 화면에서 확인할 수 있음
- [ ] /admin/orders에서 관리자가 전체 주문을 상태별로 필터링하고 고객명이나 주소로 검색할 수 있음
- [ ] /admin/orders/:id에서 관리자가 특정 주문의 상태를 직접 변경하거나 기사를 재배정할 수 있음
- [ ] /admin/customers에서 관리자가 전체 고객 목록을 조회하고 특정 고객의 전체 주문 이력을 확인할 수 있음
